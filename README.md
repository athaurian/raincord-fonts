# raincord-fonts

</div>

Hi. This repository contains font mappings and WOFF2/TTF files that replace Discord's default UI fonts (`ggsans`, `ggmono`, and `ABCGintoNord`) with **Geist** and **Geist Mono** using the [rain](https://github.com/raincord) mobile client mod.

## Install the theme

1. In rain, open the settings menu.
2. Open the **Fonts** section.
3. Tap **Install from URL** or the **+** button.
4. Tap **Import font entries from a link**.
5. Paste the raw link to the JSON mapping file:

   ```text
   https://raw.githubusercontent.com/athaurian/raincord-fonts/main/mappings/raincord/geist.json
   ```

## Mappings

- **`ggsans`** and **`ABCGintoNord`** (all weights and italics) → **Geist**
- **`ggmono`** → **Geist Mono**
